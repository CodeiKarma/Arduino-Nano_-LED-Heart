A beginner-friendly electronics project built using
Arduino Nano and 16 red LEDs.

## 🛠️ Components Used

- Arduino Nano
- 16 Red LEDs
- Current-limiting resistors
- Push button
- Perfboard
- Connecting wires

## ✨ Features

- Multiple LED patterns
- Automatic pattern change every 15 seconds
- Manual pattern change using a push button
- Heartbeat and blinking effects
- Running LED and random sparkle effects

## 🔌 Pin Configuration

| Component | Arduino Pin |
|---|---|
| LEDs 1–12 | D2–D13 |
| LEDs 13–16 | A0–A3 |
| Push Button | A4 to GND |

Note: Verify these pin assignments against
the actual hardware wiring before uploading.

## 🚀 How to Run

1. Open the `.ino` file in Arduino IDE.
2. Select Arduino Nano under Tools > Board.
3. Select the correct COM port.
4. Verify and upload the sketch.
5. Test the LED patterns.
